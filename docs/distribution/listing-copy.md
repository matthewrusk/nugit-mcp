## Short description

Save AI creations privately. Search and reuse your Nugs across assistants with optional, scoped read access.

## Full description

Keep the useful answers, ideas, plans, and instructions you create with AI. Ask your assistant to save a selected answer to NugIt and receive a private link to the original. Connect another compatible assistant to the same NugIt account to reuse your work.

Reading is optional: explicitly approve one collection or your whole library before an assistant can search or fetch existing Nugs. Reuse a voice guide, adapt a lesson outline, revisit research, or apply a saved technical approach. Existing save-only connections remain save-only.

Requires a NugIt account and a compatible client. Account capacity, client availability, and provider policies apply. Keyword search is supported; semantic search and automatic whole-chat synchronization are not advertised.

## Starter prompts

- Save that answer to NugIt.
- Find my saved brand voice in NugIt, read it, and use it for this announcement. Cite the Nug.
- Find my lesson outline in NugIt and adapt it for beginners. Cite the original.

## Reviewer summary

Three tools: `save_nug` writes a user-selected answer; `search_nugs` and `fetch_nug` require separate read consent. Authentication uses OAuth with PKCE. Read permissions can be restricted to one owned manual collection. Tools do not edit, delete, publish, share, or manage billing. See [reviewer instructions](reviewer-guide.md).

Avoid “works with every AI,” “fully open-source server,” “automatic memory sync,” or unverified approval/compatibility claims. Use platform-specific status from [the compatibility record](../compatibility.md).
