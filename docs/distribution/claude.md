# Claude Connectors Directory

The public-facing use case is reusable writing guidance, lessons, research, and business decisions. Use the [Claude setup guide](../clients/claude.md), [reviewer guide](reviewer-guide.md), [listing copy](listing-copy.md), and [permissions](../permissions.md).

Current remote submissions use the Claude.ai organization submission portal. As checked on 2026-09-18, this requires a Team or Enterprise organization and appropriate directory management access. Individual-plan users can still have custom-connector options according to their account, but that is not submission eligibility.

Before submitting:

- Complete native OAuth, save, collection-scoped retrieval, reconnect and revocation checks.
- Provide the canonical HTTPS endpoint and OAuth flow, support contact, privacy policy and terms.
- Use a dedicated reviewer account with harmless fixture Nugs; supply credentials only through the private review portal.
- Verify live tool annotations, allowed links and the current directory review requirements.
- If submitting the confirmation widget as an MCP App, provide the screenshots and paired prompts requested by the portal. This repo supplies the square icon, not fabricated screenshots or a demo.

Submit a remote connector, not a desktop MCPB bundle. The root Claude Code plugin is useful for developer installation, but does not publish a consumer Claude connector.

Reference: [official directory submission requirements](https://claude.com/docs/connectors/building/submission). Check again before submitting; portal access and asset requirements can change.
